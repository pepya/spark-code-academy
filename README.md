CodyLab Juniors 🚀
CodyLab Juniors is an interactive web platform designed to empower the next generation of creators. Built for kids ages 6–12, the site provides a structured environment to learn coding through Scratch, turning passive screen time into active, creative "skill time."

Live Site: https://codylabjuniors.lovable.app/

✨ Features
Project-Based Learning: A dedicated Lessons Page featuring step-by-step guides for creating games, animations, and digital stories.

- Gamified Achievements: A Badges System that rewards students for completing challenges and mastering new coding concepts.

- Kid-Friendly UX: A vibrant, intuitive interface designed specifically for young learners to navigate independently.

- Parental Trust: Clear curriculum pathways and independent resource disclaimers to ensure a safe learning environment.

🛠️ Tech Stack
This project was developed using Lovable and leverages the following technologies:

- Frontend: React.js with Vite for high-performance builds.

- Styling: Tailwind CSS for a responsive, modern, and colorful UI.

- Components: shadcn/ui for accessible and consistent design patterns.

Routing: React Router for seamless navigation between lessons and profiles.
